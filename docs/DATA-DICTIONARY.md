# 字幕与切版定义

- 字幕 CSV 六列 `cue_id,track,format,in,out,text`，可追加可选列 `reel`（卷号；缺省视为单卷 `R1`）。旧表头 `legacy_id,time_in,time_out` 对应 `cue_id,in,out`。UTF-8 可带 BOM。跨行引用从原件起始物理行定位。空串与 `-`、`N/A`、`NULL`、`未知` 都按缺字段处理。编号为字符串。同轨同号同卷完整内容一致只采一条，冲突全组隔离；同号跨卷是跨卷整句，不按冲突处理。
- 源时钟固定为 30000/1001 帧每秒，目标为 24 帧每秒。`FRAME` 使用整数源帧（换带后按各卷带位重新从 0 编号）。`DF` 用分号，非十整倍数分钟的首秒跳过标签 `;00`、`;01`，合法帧仍连续。`NDF` 用冒号并按名义 30 编号。`SRT`、`VTT` 代表以逗号或小数点分隔毫秒的时码列。墙钟以有理数换算源帧。
- 卷同步点 CSV 四列 `reel,format,tape,master`：`tape` 是该卷带位时码（按 `format` 解析为带位帧），`master` 是对应的母带整数帧。每卷偏移 `offset = master − tape_frame`，以有理数保形。同一卷同步点算出多个偏移时整卷留待复核（`SYNC_CONFLICT`）；保留画面的卷没有同步点记 `SYNC_MISSING`；切版未保留整卷画面（该卷只有 `REMOVE`/无切段覆盖）时缺同步点不记作待核（`exempt`）。同一带位时码在两卷出现时按各自偏移落在各自母带帧上，互不借用前一卷偏移。
- 切版 `cut,start,end,target,kind` 用左闭右开的**卷内带位帧**区间，可追加可选列 `reel`（缺省 `R1`）。类型为 `KEEP` 或 `REMOVE`。`KEEP` 必须给整数目标起帧，`REMOVE` 的 `target` 留空。同卷内源区间或目标区间重叠使整份切版失败，跨卷同坐标互不判叠。切版未覆盖区间是 `GAP`，即待证。
- 连续目标坐标为 `target + (源坐标 - start) × 1001/1250`。交付帧序号为落在区间内的整数网格点，因此两个端点都向上取整。母带帧（带位帧 + 卷偏移）随每个分段保留用于覆盖对账；卷内目标几何仍由切版目标锚点决定，偏移不会把对白挪出本卷画面。显示出的目标重叠按轨道对交付整数帧做扫描线，重叠深度大于等于两条的每一帧只计一次。
- 跨卷整句（同轨同号出现在多卷）只对齐半边时：该句所有 `KEEP` 分段统一标 `HALF_SYNC` 暂扣，签发包不得只放半句；`signable` 与 `withheld` 在覆盖账中分别计量且二者之和等于 `delivered`。
- 源覆盖在同一轨内取并集，再对不同轨道累加。所有源帧量用十进制整数字符串或 `分子/分母`。原覆盖 = 已交付源覆盖 + 剪辑移除 + 待证。时码无效或身份矛盾无法估时，行数单计。证据 JSON 含原件、行证、散列、规则版本、归档 UTC 以及用过的同步点（卷、原行、带位时码、母带帧、偏移）与各卷复核状态。晚到的同步记录补齐后重新提交即按新输入散列重算并生成新档号。
