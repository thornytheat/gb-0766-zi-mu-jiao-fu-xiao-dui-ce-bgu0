# 换带卷同步复算例（taped）

旧片换带后带位时码从 0 重新编号，同一标签在两卷不是同一画面。

## 同一时码各自落画

C301（R1）与 C302（R2）的带位入点都是 `FRAME 100`。两卷同步点都给出偏移 1800：

- R1：同步点 `FRAME 100 → 母带 1900`、`FRAME 200 → 母带 2000`，偏移恒为 1800，C301 母带区间 `[1900,1940)`。
- R2：同步点 `FRAME 100 → 母带 1900`、`FRAME 300 → 母带 2100`，偏移恒为 1800，C302 母带区间 `[1900,1940)`。

切段按卷内带位几何锚定：R1 切段 `R1-A` 目标起帧 0，C301 交付 `[81,113)`；R2 切段 `R2-A` 目标起帧 500，C302 交付 `[581,613)`。同号时码没有借用前一卷偏移，两句对白落在各自画面上。

## 同卷偏移冲突

R3 同步点 `FRAME 100 → 母带 3000`（偏移 2900）与 `FRAME 200 → 母带 3200`（偏移 3000）不一致，R3 整卷状态 `conflict`，卷内字幕隔离为 `SYNC_CONFLICT`。

## 跨卷半句

C303 同号出现在 R2 与 R3。R2 半边可对齐、R3 半边待核，映射后两个 `KEEP` 分段都标 `HALF_SYNC`：覆盖账 `delivered=100` 中 `signable=40`、`withheld=60`，签发包校验返回 409 `HALF_SENTENCE`。

## 整卷移除免待核

R4 只有 `REMOVE` 切段，C304 没有任何保留画面。该卷无同步点时状态为 `exempt`，不产生 `SYNC_MISSING`，字幕计入 `exempt_cues` 而不进覆盖账。

## 晚到同步记录

把 R3 的同步记录纠正为统一偏移 2900（`FRAME 100→3000`、`FRAME 200→3100`、`FRAME 300→3200`）后重新提交：输入散列变化产生新档号，重算后四卷状态为 `ok/ok/ok/exempt`，暂扣清零，下载的证据包 `sync_evidence.points` 含全部 7 条同步点及其原行、带位时码、母带帧与偏移。
